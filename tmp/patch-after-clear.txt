# 2026-11-14：把 DSH 进程的临时目录从 C 盘 %TEMP% 迁到 D:\dsh-temp，
# 并在启动 5s 后清理超过 24h 未更新的 dsh-workspace-changes-* 残留目录。
#
# 原因：内置插件 @deepseek-ai/dsh-workspace-changes 的临时根目录写死 os.tmpdir()
# （源码 `tempRoot: tmpdir()`，config 只有 timeoutMs/outputMaxBytes/maxFiles/
# maxFileBytes/diffTimeoutMs，没有 tempDir 也没有开关）。每个顶层会话首轮快照会
# git add -A 整个工作树（未跟踪且未被 .gitignore 排除的文件全写成 git 对象），
# 只有 session/disposed 才 rm -rf；进程被强杀就成了残留，2026-10 那批单个达 2.64GB。
#
# 原理：Node 的 os.tmpdir() 在 Windows 上每次调用都重读 TMPDIR/TMP/TEMP，
# 插件在加载期改 env 即可；workspace-changes 的 scratchDir() 是每个 Session
# 首次用时才算的，必然晚于插件加载。
#
# 生效：重启 DSH。只影响 DSH 进程及其子进程（git/node/pwsh 的 temp 一起搬）。
