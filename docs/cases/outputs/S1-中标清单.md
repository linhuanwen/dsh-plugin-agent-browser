## 3. 抽查两条金额单位（案例要求的回访核对）

1. **茂名（#4）**：摘要「总中标金额 ￥329.100000 万元」↔ 正文「3,291,000.00 元」→ 329.1 × 10000 = 3,291,000 ✅ 一致。
2. **内蒙古（#3）**：摘要「￥5391.828000 万元」↔ 三个合同包 35,270,200 + 16,060,080 + 2,588,000 = 53,918,280 元 = 5391.828 万元 ✅ 一致（注意是 3 个合同包合计，不是单一供应商）。
3. **附带发现（口径问题，不是数据错误）**：枣阳（#2）摘要「总中标金额 ￥0.000000 万元」，正文「中标金额 1027.000000(万元)」——摘要字段没被站点填值。清单以正文为准并在此登记，避免后续复算时误判「0 元」。
4. **附带发现（分类口径）**：`ERR_SSL_PROTOCOL_ERROR` 被判成 `nav_cert`（文案写「the certificate was rejected」）。实际是端口协议不匹配，不是证书问题；属 `plugin/navigation.js` 的规则归类偏粗（`ERR_SSL_` 前缀统一归 cert）。已在 `docs/cases/014` §3 S1「观察」中登记，待后续是否细化为独立 stage。
